# Changelog

## [19.0.1.0.0] - 2026-08-24

### Ajouté
- Modèle SaasPlan pour la gestion des formules et plans
- Modèle SaasInstance pour les instances Odoo déployées
- Modèle SaasSubscription pour les souscriptions clients
- Modèle SaasResource pour le suivi des ressources
- Endpoints API RESTful complets
- Vues formulaire et liste pour tous les modèles
- Système de gestion des alertes pour les ressources
- Suivi automatique du stockage et des utilisateurs
- Système de renouvellement automatique
- Rapports PDF personnalisés
- Tâches planifiées pour maintenance
- Controles d'accès basés sur les rôles
- Documentation complète

### Fonctionnalités principales
- Création et gestion des instances
- Activation/suspension/suppression des instances
- Gestion des plans et tarification flexible
- Suivi des souscriptions par client
- Monitoring des ressources avec alertes
- Allocation automatique des ressources
- Renouvellement automatique des souscriptions
- Historique complet des modifications (message_ids)
- Notifications d'expiration prochaine
