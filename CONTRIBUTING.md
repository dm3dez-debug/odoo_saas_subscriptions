# Contribution Guidelines

## Comment Contribuer

Nous accueillons les contributions de tous les développeurs ! Voici comment vous pouvez contribuer :

### 1. Fork le projet
```bash
git clone https://github.com/votre-username/odoo_saas_subscriptions.git
cd odoo_saas_subscriptions
```

### 2. Créer une branche feature
```bash
git checkout -b feature/votre-fonctionnalite
```

### 3. Faire vos modifications
- Respectez le style de code existant
- Ajoutez des tests pour les nouvelles fonctionnalités
- Mettez à jour la documentation

### 4. Commit et Push
```bash
git add .
git commit -m "Add: Description de votre fonctionnalité"
git push origin feature/votre-fonctionnalite
```

### 5. Ouvrir une Pull Request
- Créez une PR vers la branche `develop`
- Fournissez une description claire
- Référencez les issues associées

## Standards de Code

- Respectez PEP 8 pour Python
- Utilisez des noms de variables explicites
- Documentez vos fonctions
- Évitez les code duplicates
- Testez votre code avant de soumettre

## Types de Contributions

### Bug Fixes
- Décrivez le bug clairement
- Fournissez les étapes de reproduction
- Incluez la correction proposée

### Nouvelles Fonctionnalités
- Discutez d'abord dans les issues
- Suivez l'architecture existante
- Maintenez la compatibilité arrière

### Améliorations
- Optimisations de performance
- Clarification du code
- Meilleure gestion des erreurs

## Processus de Review

Toutes les PRs seront reviewées par l'équipe de maintenance. Les commentaires et demandes de modification doivent être adressés avant la fusion.
